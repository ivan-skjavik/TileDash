💻 Implementation Code

Package Installation

npm install @shoelace-style/shoelace

Basic Setup in Vite/TypeScript

// main.ts or app initialization import '@shoelace-style/shoelace/dist/themes/light.css'; import { setBasePath } from '@shoelace-style/shoelace/dist/utilities/base-path.js'; // Set the base path for Shoelace assets setBasePath('https://cdn.jsdelivr.net/npm/@shoelace-style/shoelace@2.15.1/cdn/');

TypeScript Integration

// types/shoelace.d.ts import '@shoelace-style/shoelace/dist/components/switch/switch.js'; import '@shoelace-style/shoelace/dist/components/range/range.js'; import '@shoelace-style/shoelace/dist/components/badge/badge.js'; import '@shoelace-style/shoelace/dist/components/icon/icon.js'; declare global { namespace JSX { interface IntrinsicElements { 'sl-switch': any; 'sl-range': any; 'sl-badge': any; 'sl-icon': any; } } }

AppliancesTile with Shoelace (Example)

// AppliancesTileShoelace.ts private createToggleControl(appliance: ApplianceDevice): HTMLElement { const { device, id } = appliance; const isOn = device.capabilitiesObj?.onoff?.value ?? false; // Create Shoelace switch const switchElement = document.createElement('sl-switch') as any; switchElement.checked = isOn; switchElement.addEventListener('sl-change', (e: any) => { this.debouncedToggleUpdate(id, e.target.checked); }); // Create control container const container = this.createControlContainer(device.name, 'Switch • Living Room'); container.querySelector('.control-item__control')?.appendChild(switchElement); return container; } private createDimmerControl(appliance: ApplianceDevice): HTMLElement { const { device, id } = appliance; const dimValue = Math.round((device.capabilitiesObj?.dim?.value ?? 0) * 100); // Create Shoelace range const rangeElement = document.createElement('sl-range') as any; rangeElement.min = 0; rangeElement.max = 100; rangeElement.value = dimValue; rangeElement.addEventListener('sl-change', (e: any) => { this.debouncedSliderUpdate(id, e.target.value); }); // Create control container const container = this.createControlContainer(device.name, 'Light • Living Room'); container.querySelector('.control-item__control')?.appendChild(rangeElement); return container; }

CSS Customization

/* Custom Shoelace theme for TileDash */ :root { --sl-color-primary-600: #667eea; --sl-color-success-600: #4CAF50; --sl-border-radius-medium: 8px; } /* Dark theme overrides for appliances tile */ .appliances-tile sl-switch::part(control) { border-color: rgba(255, 255, 255, 0.3); background-color: rgba(255, 255, 255, 0.1); } .appliances-tile sl-switch[checked]::part(control) { background-color: var(--sl-color-success-600); border-color: var(--sl-color-success-600); } .appliances-tile sl-range::part(base) { --track-color-active: var(--sl-color-success-600); --track-color-inactive: rgba(255, 255, 255, 0.3); --thumb-color: white; }

🚀 Recommendation

I recommend adopting Shoelace for the following reasons:

  • Faster Development: Significant reduction in custom component code
  • Better Accessibility: Built-in ARIA support and keyboard navigation
  • Professional Quality: Well-tested, polished components
  • Future-Proof: Active maintenance and regular updates
  • Customizable: CSS custom properties and shadow parts for theming
  • TypeScript Ready: Full TypeScript support available

Migration Strategy:

  1. Start with new tiles using Shoelace
  2. Gradually migrate existing tiles
  3. Keep current MaterialControls as fallback during transition
  4. Create a unified theme that works with both systems
